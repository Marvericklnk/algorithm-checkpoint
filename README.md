# Sentence Counting Algorithm

A GoMyCode pseudocode exercise that counts characters, words and vowels in a sentence.

## Read the algorithm

Open [algorithm.txt](algorithm.txt). Trace the instructions by hand; this is pseudocode, so it does not run directly in a browser or with Node.js.

The input must end with a period. The character count includes the final period. Word counting assumes single spaces between words, with no leading or trailing spaces.

## Example

For `Hello world.`, the expected output is:

- Characters: 12
- Words: 2
- Vowels: 3
